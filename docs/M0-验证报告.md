## 2. 步骤

```bash
bash scripts/install-deps.sh          # 安装 macFUSE + ntfs-3g，重启并允许系统扩展
bash scripts/verify-backend.sh        # 采集环境信息，粘贴到第 1 节
sudo bash scripts/m0-poc.sh /dev/disk4s1
```

脚本会：卸载系统只读挂载 → 创建挂载点 → `ntfs-3g -o local,allow_other,auto_xattr` 挂载 →
写入 `ntfs4mac-poc-<时间戳>.txt` → `sync` → 卸载。
