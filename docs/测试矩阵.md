# 测试矩阵（M4 稳定性加固）

> 所有写入类测试必须使用闲置磁盘，并在测试前备份数据。
> 未在真机执行的项请保持未勾选，不要默认视为通过。

## 1. 环境维度

| 维度 | 覆盖项 | 结果 |
|---|---|---|
| 系统 | macOS 12 / 13 / 14 / 15 / 26 / 27 | ☐ |
| 芯片 | Intel / M1 / M2 / M3 / M4 | ☐ |
| 介质 | USB SSD / USB HDD / SD 卡 / 磁盘映像（dmg 内 NTFS） | ☐ |
| 后端 | kext（12–15）/ FSKit（26+，待实测） | ☐ |
| 特权方式 | LaunchDaemon 免密 / osascript 弹窗 / 均不可用 | ☐ |

| 编号 | 场景 | 预期 | 结果 |
|---|---|---|---|

| T04 | 单大文件（>10 GB）读写 | 传输完成、校验一致 | ☐ |
| T05 | 海量小文件（>5 万）读写 | 无丢文件，Finder 可正常浏览 | ☐ |
| T06 | Windows 休眠 / 快速启动锁定 | 返回 `HIBERNATED`，保持只读，不写入 | ☐ |
| T07 | 卷被应用占用时卸载 | 返回 `VOLUME_BUSY`，可确认后强制卸载 | ☐ |

| T13 | 只读模式挂载 | 写入返回只读错误，不破坏卷 | ☐ |

## 3. 代码层加固对照

| 风险 | 实现 |
|---|---|
| ntfs-3g 非线程安全 | `MountEngine.enqueue` 单队列，所有 mount/unmount 串行 |
| 休眠卷被强挂 | 不注入 `remove_hiberfile`；`HIBERNATED` 直接失败并给指引 |
| 双重挂载 | 挂载前检测 `mounted` 并先卸载，校验挂载表后才报成功 |
| 挂载假成功 | 轮询 `/sbin/mount` 最多 12 秒，进程提前退出则读取日志尾部映射错误 |
| 卸载假成功 | 卸载后复查 `diskutil info`，仍挂载则返回 `VOLUME_BUSY` |
| 并发点击 | 控制器按卷设置 `busy`，重复请求直接拒绝 |
| 命令注入 | 特权层全部使用 argv 数组；osascript 路径逐参数 shell 转义；白名单校验 |
| 日志缺失 | 每次挂载写入 `/var/log/ntfs4mac/mount-<dev>-<ts>.log`，UI 可直接打开目录 |

## 4. 已知限制

- FSKit 后端（macOS 26+）尚未真机验证，行为可能与 kext 不同。
- 不支持休眠卷写入、NTFS 修复、格式化、BitLocker/加密卷。
- 用户态实现吞吐低于 Windows 原生驱动，不作为性能基准。
- 未签名/未公证版本在 Gatekeeper 下需手动放行（见发布清单）。
