# 发布检查清单（M5 分发）

## 1. 签名与公证

- [ ] 申请 Developer ID Application 证书，导入钥匙串
- [ ] 编译并签名助手：
      `CODESIGN_IDENTITY="Developer ID Application: xxx" bash scripts/build-helper.sh`
- [ ] Electron 应用签名：`npm run dist:mac`（`electron-builder.yml` 已配置 hardenedRuntime + entitlements）
- [ ] 助手二进制放入应用 `Resources/bin` 后重新签名，避免嵌套签名失效
- [ ] 提交公证：`xcrun notarytool submit release/*.dmg --keychain-profile <profile> --wait`
- [ ] 装订票据：`xcrun stapler staple release/*.dmg`
- [ ] 清洁机验证：`spctl -a -vvv -t install release/*.dmg` 无警告

## 2. 安装体验

- [ ] DMG 背景、图标、Applications 快捷方式正常
- [ ] 首次启动展示数据安全免责声明
- [ ] 未安装 macFUSE 时引导页可完成依赖安装
- [ ] 未安装助手时自动回退管理员弹窗，且提示清晰
- [ ] 卸载应用后 `/Library/LaunchDaemons/com.ntfs4mac.helper.plist` 有清理说明

## 3. 合规

- [ ] ntfs-3g（GPLv2）保持独立进程调用，不分发其二进制源码包的修改版本
- [ ] 不内嵌 macFUSE kext；安装引导跳转官方渠道
- [ ] 应用内展示第三方组件与许可证说明
- [ ] 隐私政策：不收集磁盘内容、不上传日志
- [ ] 避免使用「文件系统内核扩展」等敏感描述触发公证审核问询

## 4. 发布物

- [ ] `release/NTFS for Mac-<version>-arm64.dmg`
- [ ] `release/NTFS for Mac-<version>-x64.dmg`
- [ ] `CHANGELOG.md` 更新
- [ ] README 更新支持矩阵与已知问题
- [ ] 测试矩阵（`docs/测试矩阵.md`）勾选完成并归档

## 5. 回滚预案

- [ ] 保留上一版本 DMG 与校验值
- [ ] 记录已知问题与临时规避方式（只读挂载、手动 `diskutil unmount`）
- [ ] 发布后监控启动失败与挂载失败日志的反馈渠道
